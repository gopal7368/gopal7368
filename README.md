- 🔹 **[NIRF Visualization Dashboard](https://github.com/gopal7368/nirf-visualization)**  
  📊 Developed an interactive web app for visualizing NIRF rankings using React and Streamlit.  
  Includes features like parameter-wise trends, institution profiles, historical comparisons, and dynamic filters.

- 🔹 **[Clip Scholar – Notes and Quiz Generator from YouTube](https://github.com/gopal7368/clip-scholar)**

  - **Extraction** (Exact hazard reason & product name)
